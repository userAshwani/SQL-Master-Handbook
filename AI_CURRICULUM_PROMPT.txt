══════════════════════════════════════════════════════════════════
REPO PHILOSOPHY
══════════════════════════════════════════════════════════════════

This is a PROGRESSIVE, MULTI-PROJECT SQL learning repo.
The learner builds real, industry-grade data systems step-by-step:

  Isolated practice queries
        ↓
  Build each sub-module (queries unlock modules)
        ↓
  Wire all sub-modules into one runnable final project
        ↓
  Move to the next main project (harder domain, new skills)

Each MAIN PROJECT introduces one industry domain (reporting, schema design,
access control, analytics, optimization, ETL, warehousing, etc.) and is fully
self-contained. Questions are numbered sequentially across ALL projects — they
never reset.

Dialect: portable, ANSI-ish SQL that runs unmodified in SQLite (no server
required). Avoid vendor-specific extensions — no DELIMITER-based stored
procedures, no MySQL-only functions, no document/aggregation-pipeline syntax.
Stick to standard SELECT/JOIN/CTE/window-function/VIEW/TRIGGER/CONSTRAINT SQL
that any relational engine understands.
